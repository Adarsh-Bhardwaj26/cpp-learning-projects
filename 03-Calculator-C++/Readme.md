# 🧮 C++ Stack Calculator

A simple calculator I built while practicing **C++** and learning how stacks can be used to evaluate mathematical expressions.

## What I Practiced

- `stack` from the C++ STL
- Operator precedence
- Bracket handling: `()`, `[]`, `{}`
- Functions and basic error handling
- Expression evaluation
- Working with strings and characters

## Supported Operators

`+` `-` `*` `/` `%`
