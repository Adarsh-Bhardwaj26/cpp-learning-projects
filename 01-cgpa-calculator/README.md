# CGPA Calculator

A simple C++ console-based CGPA Calculator that calculates CGPA based on course credits and grades. The calculated CGPA is also saved to `Output.txt` along with the date.

## Features

- Calculate CGPA for multiple subjects
- Supports grades from S to F
- Takes individual course credits into account
- Validates grades
- Saves CGPA history to `Output.txt`
- Allows recalculating without restarting the program

## Grade System

| Grade | Grade Point |
|-------|-------------|
| S     | 10          |
| A     | 9           |
| B     | 8           |
| C     | 7           |
| D     | 6           |
| E     | 5           |
| F     | 0           |
