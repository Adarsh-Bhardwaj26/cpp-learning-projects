# ✊ Rock Paper Scissors

A simple **Rock Paper Scissors** game I built while practicing **C++**.

The computer randomly chooses rock, paper, or scissors, and the program checks who wins.

## What I Practiced

- Random number generation
- Functions
- Conditional statements
- `while` loops
- Character input
- Basic game logic
- C++ `<random>` library

## How to Play

Enter:

- `r` for Rock
- `p` for Paper
- `s` for Scissors
- `0` to close the program
- `1` to play
